# Finance Accounting App

Finance accounting app with a simple English UI and a Go-based double-entry accounting engine.

## Workspace Status

Repository ini sedang memasuki Base dan MVP 1. Dokumen spesifikasi ada di root; implementasi berada di `backend/` dan `web/`.

## Commands

```text
make backend-build
make backend-test
make web-install
make web-build
```

## AI Agent Workflow

Baca `AGENTS.md`, claim task di `docs/TASK_LEDGER.md`, kerjakan hanya owned paths, tambahkan tests, update `docs/CHANGELOG.md`, dan jalankan verification gate sebelum menyelesaikan task.
